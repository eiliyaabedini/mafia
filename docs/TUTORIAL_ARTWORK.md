# Tutorial artwork

Four original illustrations generated once with the built-in image generation tool. The game bundles the assets; opening a tutorial does not generate images or make model calls. Persian captions are rendered as accessible app text rather than baked into the artwork.

Delivery: 1200×800 WebP, quality 86, in `shared/src/commonMain/composeResources/drawable`. Originals are retained in the generation session directory.
